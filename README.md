⸢ Earl Triggs — Portfolio ⸥

> “Think IT. Build IT. Own IT.”

A personal portfolio website built using HTML, CSS, and JavaScript.

This project showcases my:
- projects
- technical skills
- hobbies
- interactive UI experiments
- terminal-inspired aesthetic

The website was designed with a minimalist / cyber-central inspired theme and includes various animated effects, hidden details, and interactive elements.

## Features

- Animated typing effects
- Dynamic greeting text (with a 1/100 chance to see a rare text)
- Featured projects carousel
- Interactive hobby carousel
- Dark / Light theme toggle
- Floating terminal popups
- Smooth UI animations
- Responsive layout
- Hidden easter eggs & references that I added for fun

## Built With

- HTML5
- CSS3
- JavaScript
